# Lucky Number

Lucky Number is a small Java console game. The computer chooses a secret number from 1 to 20, and you try to guess it in six tries. After each guess, the game tells you whether to go higher or lower.

## How to play

1. Start the game using the instructions below.
2. Enter a whole number from 1 to 20 when prompted.
3. Use the “Too low” and “Too high” hints to guide your next guess.
4. Guess correctly within six tries to win the round.
5. Enter `y` to play another round or `n` to quit. Enter `q` during a round to end that round early.

## Run it

You need a Java JDK installed. From this folder, compile and run:

```sh
javac LuckyNumber.java
java LuckyNumber
```
